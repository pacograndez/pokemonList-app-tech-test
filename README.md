# Proyecto LitElement pokemonList-app-tech-test

Este es un proyecto creado con [LitElement](https://lit.dev/), una librería para construir componentes web rápidos y reutilizables.

## Requisitos previos

Antes de ejecutar el proyecto, asegúrate de tener instalados los siguientes programas en tu máquina:

- [Node.js](https://nodejs.org/) (v14 o superior)
- [npm](https://www.npmjs.com/) (v6 o superior)

## Instalación

1. Clona este repositorio en tu máquina local:

   ```bash
   git clone https://github.com/pacograndez/pokemonList-app-tech-test
   cd pokemonList-app-tech-test

2. npm install para instalar dependencias.
3. npm run star para empezar a correr el proyecto.
4. El proyecto se ejecutará en http://localhost:8000/
